# Roadmap

Pocket Codex should stay useful as a daily tool before it grows ambitious.

## Version 0.1

- Private Telegram text chat.
- Project and session selection.
- SQLite conversation storage.
- OpenAI Responses API.
- Local polling deployment.

## Version 0.2

- Finer-grained command authorization for `/run` and `/ssh`.
- Explicit file commands, such as `/read path/to/file.py`.
- Project search over allowlisted folders.
- Per-project prompt presets.
- Export a session to Markdown.

## Version 0.3

- Voice input handling from Telegram voice messages.
- Optional text-to-speech replies.
- Memory records with manual approve/edit/delete controls.
- Daily digest for selected projects.

## Version 1.0

- Multi-user roles.
- Encrypted local database option.
- Webhook deployment mode for cloud servers.
- Plugin interface for project tools.
